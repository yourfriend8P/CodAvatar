# Task Manager API

A backend development learning project focused on Python, FastAPI, PostgreSQL, REST APIs, and testing.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Git and GitHub

## Project Goals

- Learn Python for backend development.
- Build REST APIs using FastAPI.
- Implement CRUD operations.
- Integrate PostgreSQL.
- Write automated tests.
- Follow proper backend development practices.
